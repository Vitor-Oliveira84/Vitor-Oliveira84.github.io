// 05 — metodologias & frameworks

Como eu trabalho

Cada engajamento segue frameworks reconhecidos pela indústria — garantindo cobertura estruturada, reprodutibilidade e relatórios que fazem sentido para times técnicos e executivos.

ATT&CK

MITRE ATT&CK

Base principal para mapeamento de TTPs. Cada técnica explorada é catalogada com ID correspondente, facilitando a comunicação com times de defesa e a criação de regras de detecção.

Tactics Techniques Sub-techniques
PTES

Penetration Testing Execution Standard

Framework que guia o ciclo completo de um pentest: pré-engajamento, reconhecimento, modelagem de ameaças, exploração, pós-exploração e relatório.

Pre-engagement Exploitation Reporting
OWASP

OWASP Testing Guide

Referência para testes em aplicações web e APIs. Utilizado para garantir cobertura sistemática de vulnerabilidades, do OWASP Top 10 a falhas de lógica de negócio.

Top 10 API Security Mobile Top 10
KillChain

Cyber Kill Chain

Modelo da Lockheed Martin aplicado para estruturar operações de red team em fases sequenciais: reconhecimento, weaponização, entrega, exploração, instalação, C2 e ação nos objetivos.

Recon C2 Actions on Objectives
OSSTMM

Open Source Security Testing Methodology

Metodologia abrangente para testes de segurança em redes, sistemas e processos. Útil para engajamentos que exigem métricas quantitativas de exposição e risco.

Network Security Risk Metrics Operational Security
TIBER

TIBER-EU Framework

Framework europeu para red team baseado em inteligência de ameaças reais (Threat Intelligence-Based Ethical Red Teaming), voltado a organizações financeiras e infraestrutura crítica.

Threat Intel Red Team Financial Sector
