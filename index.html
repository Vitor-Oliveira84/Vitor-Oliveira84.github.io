🔴 Red Team

Simular adversários reais em operações estruturadas de teste de segurança.

Fases do Red Team

1. Reconhecimento (OSINT passivo) 2. Weaponização (criar payloads) 3. Entrega (phishing, watering hole) 4. Exploração (explorar vulnerabilidade) 5. Instalação (persistência) 6. C2 (Command & Control) 7. Ações nos Objetivos (lateral movement, data exfil)

Ferramentas principais

nmap -sS -p- target.com subfinder -d target.com BloodHound (AD mapping) Burp Suite (web testing) Metasploit (exploitation) HAVOC C2 (command & control)

🔍 Pentest

Teste de penetração estruturado para identificar vulnerabilidades em sistemas, aplicações e infraestrutura.

Fases do Pentest

1. Reconhecimento 2. Scanning (vulnerabilidades) 3. Enumeração 4. Exploração 5. Pós-exploração 6. Relatório

Ferramentas por fase

  • Scanning: Nmap, Nessus
  • Web: Burp Suite, OWASP ZAP
  • Exploitation: Metasploit, Impacket
  • Reporting: Burp, Nessus, Dradis

accesschk64.exe -accepteula -nobanner /w "Authenticated Users" c:\ sc query state=all | findstr /i "SERVICE_NAME"

🔵 Burp Suite

Funcionalidades principais

  • Proxy: Interceptar/modificar requests HTTP
  • Scanner: Scan automático de vulnerabilidades
  • Intruder: Fuzzing e brute-force
  • Repeater: Testar requests customizadas

Workflow básico

1. Configurar proxy (127.0.0.1:8080) 2. Target → Scope → Add target URL 3. Navegar no browser (tráfego capturado) 4. Proxy → Intercept → Review requests 5. Scanner → Active/Passive Scan 6. Issues → Revisar vulnerabilidades

🪟 Windows — Ofensivo & Defensivo

Técnicas ofensivas

# PowerShell powershell.exe -ep bypass -c "IEX(...)" # CMD cmd.exe /c "..." # WMI wmic process call create "cmd.exe /c beacon.exe"

O que monitorar (Detecção)

  • PowerShell.exe -ep bypass (bypass de execution policy)
  • cmd.exe /c (execução silenciosa)
  • Process injection (VirtualAllocEx + WriteProcessMemory)
  • LSASS access (credential dumping)
  • Registry modification (RUN keys, scheduled tasks)

# Processos com conexões abertas netstat -tlnp lsof -i -P -n # Logs tail -f /var/log/auth.log history # Persistence (cron, ssh, bashrc, systemd) crontab -l ~/.ssh/authorized_keys

🔴 Threat Detection

Tipos de detecção

  • Signature-based: Pattern matching conhecido
  • Anomaly-based: Desvio do comportamento normal
  • Behavioral: Análise de cadeia de atividades

Sigma rules (genéricas)

title: PowerShell execution from temp logsource: product: windows detection: selection: Image|endswith: 'powershell.exe' CommandLine|contains: - 'Temp' - 'Downloads' condition: selection

⚙️ Detection Rule Tuning

Estratégia

1. Whitelisting (adicionar processos legítimos) 2. Correlação (combinar múltiplos indicadores) 3. Contextualização (horário, usuário, localização) 4. Métricas (TP vs FP)

Métricas

Precision = TP / (TP + FP) Recall = TP / (TP + FN) F-score = 2 * (Precision * Recall) / (Precision + Recall)
